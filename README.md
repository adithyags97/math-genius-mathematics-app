# MathGenius — Mathematics Learning Lab

A free, responsive web application for a first-year engineering Mathematics Application project.

## Features
- Scientific calculator (basic operations, powers, square root, trigonometry, logs)
- Quadratic and linear equation solver
- Function graph plotter
- Searchable mathematics formula library
- Statistics calculator (mean, median, mode, range, population standard deviation)
- Five-question practice quiz with feedback
- Responsive layout for laptop and mobile screens

## Run on your Mac
1. Download and unzip `MathGenius-Project.zip`.
2. Open the `mathgenius_project` folder.
3. Double-click `index.html` to open it in your browser.
4. For editing, open the folder in a code editor such as Visual Studio Code.

## Publish using GitHub Pages
1. Sign in to GitHub and create a new repository, e.g. `mathgenius-mathematics-app`.
2. Set it to **Public** if you want to publish free with GitHub Pages.
3. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes and refresh the Pages section to get the published website link.

## Important project note
This is a client-side educational prototype. It does not connect to an AI model or an external service. Trigonometric functions use radians. Standard deviation is calculated as a population standard deviation.

## Suggested demonstration
1. Calculate `(12+8)*3` in the calculator.
2. Solve `x² - 5x + 6 = 0` by setting a=1, b=-5, c=6.
3. Plot `x^2 - 4` and point out where the graph crosses the x-axis.
4. Search the formula library for “derivative”.
5. Analyze `12, 15, 18, 18, 22, 25, 30`.
6. Complete the quiz and show the score.
